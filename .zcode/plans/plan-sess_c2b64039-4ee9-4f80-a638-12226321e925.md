## 归零工具 v2——按你的思路重做

**核心变化**：不再"打开一件弹一件关一件"，而是**复用主脚本的标准件选择框，选中的一次性加载到当前部件里，全部摆在一起逐件定位，最后统一写回文件**。

### 流程
1. **选择窗口**——直接 `import nx_extrude_runner` 复用它的标准件选择对话框（窗口①同款，本机天天在用，零重复代码）；默认全选，取消=退出。
2. **加载到当前部件**——对选中每一件：以组件方式（0,0,0 恒等姿态）加进当前显示部件 → 提升为独立体（**主脚本放置标准件的同款已验证代码路径**）→ 该件所有实体归入以文件名命名的组（如 `ZERO_大水口-18`，组名+体名双标识，解决"一件多实体"问题）→ 删组件壳。全选时 14 件平铺在当前视图。
3. **逐件指定定位点**——依序弹"指定点"小对话框（已补上缺失的初始化回调）；每确认一件，**当场把该件组平移到 0,0,0**，你在视图里立刻看到它归位；全部点完 = 全部归位，所见即所得。
4. **写回文件**——按记录的位移逐件：打开原始 prt → 整体平移 → 另存 `stdparts_归零/` → 关闭（此阶段无 UI 很快；`--dry-run` 只看不写）。
5. **清理**——删掉当前部件里的 ZERO_ 副本组（全程 UndoMark 包裹，Ctrl+Z 可回滚），信息窗口汇总每件位移。

### 关键保证
- **坐标 1:1 对应**：组件按恒等姿态放置，当前部件里点到的坐标 = prt 文件里的坐标，位移可直接用于写回，无翻转/换算逻辑
- **安全性不变**：原始 prt 一律不动；中止时已确认的件仍写回
- **上轮崩溃根因已修**：对话框补注册 `AddInitializeHandler`（与主脚本一致）
