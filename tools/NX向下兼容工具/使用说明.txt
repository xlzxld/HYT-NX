NX 向下兼容工具 —— 使用说明
=====================================

【这套工具是干什么的】
NX 的 .prt 只向下兼容：新版本存的 prt，旧版本打不开，NX 也无法把 prt 降级另存。
本工具用 Parasolid 中性格式当载体，把 NX2312 母版标准件下放到 NX8 ~ NX2312
任意版本：

    stdparts\*.prt (NX2312 母版)
        → export_xt.py        导出 .x_t（Parasolid 24.0 = NX8 schema）
        → 低版本 NX 上跑 import_xt_to_prt.py
        → 还原出 prt（prt 格式 = 执行导入那台 NX 的版本）

代价：导入得到的是「哑实体」，见下【局限】。


【文件清单】
  export_xt.py         导出：prt → x_t。在本机（NX2312）的 NX 里跑。
  verify_import.py     校验：把 x_t 逐个回读导入数实体，核对零丢失。本机跑。
  import_xt_to_prt.py  导入：x_t → prt。在低版本 NX 机器上跑。
  一键导入.bat         低版本机器上双击用（自动找 NX 安装路径）。
  使用说明.txt         本文件。
  xt\                  导出产物 x_t 统一放在这个子目录里。

  以下都是脚本运行时自动生成、可随时删的东西：
  export_log.txt、verify.txt、import_log.txt（三个日志）；
  stage\、tmp\（ASCII 暂存区，脚本跑完会自动删除）；
  x_t转prt\（导入产出的 prt，在 xt\ 旁边）。


【流程 A：本机导出（NX2312）】
1. NX 里：文件 → 执行 → NX Open → 选 export_xt.py
   14 个 x_t 直接生成在本文件夹的 xt\ 子目录（ASCII 暂存法，无需任何手工
   拷贝；暂存目录 stage\ 跑完自动删除）。
   日志 export_log.txt，确认末尾 DONE ok=14 fail=0。
2. 接着跑 verify_import.py 回读校验，看 verify.txt：
   14 行 [OK]、末行 problems=0 即通过。
3. 实体数对照表见下，逐个核对有没有丢东西。


【流程 B：低版本机器导入（NX8~NX2312 通用）】
1. 把整个文件夹拷到目标机器（建议放纯英文路径，例如 C:\nxpkg\）。
2. 双击 一键导入.bat；或在 NX 里 文件 → 执行 → NX Open → 选
   import_xt_to_prt.py。两种方式效果一样。
3. prt 生成在 xt\ 旁边的 x_t转prt 文件夹里（都在本包内）；日志 import_log.txt
   在本文件夹（包根），跑完检查有没有 [FAIL] 行。
4. 注意：产出 prt 的格式 = 目标机器的 NX 版本。在 NX8 机上跑得 NX8 格式
   （兼容面最宽，NX8 及以上都能开）；在 NX10 机上跑得 NX10 格式（NX8 打不开）。
   要给更低版本的 NX 用，就在那台低版本 NX 上跑导入。
5. 若供 nx_extrude_runner 装配使用：把 x_t转prt 里的 prt 直接拷回项目根的
   stdparts\ 目录（覆盖同名即可；runner 固定按 stdparts 目录读，无版本切换）。


【为什么有 ASCII 暂存】（踩过的坑，别改回去）
NX10 默认本地代码页模式（GBK），见到 UTF-8 中文路径/文件内嵌中文名就报
「期望的是语言环境数据，但检测到 UTF8 数据」。所以导出、导入两侧都先把文件
复制成 p000.prt / i000.x_t 这种纯英文名交给 NX 处理，中文的改名活儿全由
Python（Unicode 安全）完成，NX 全程只见过纯 ASCII 路径。

【已经确认过的事】
- x_t 是 Parasolid 24.0（NX8 schema），NX8 / NX10 / NX12 及更新版本都能直接读。
- 源件全部毫米单位，脚本按毫米新建部件，不会出现尺寸差 25.4 倍的问题。
- 导入后实体名为空（不是残留英文名），没有副作用。
- 14 个 x_t 已回读验证，实体数与源件逐个吻合，零丢失。


【局限（必须知道）】
- 导入得到的是「哑实体」：只有几何体，没有特征树、草图、表达式。想改尺寸只能
  用同步建模推面，改不了原始参数。要保留参数历史，只能在低版本 NX 里重新
  建模，或找一台对应版本的机器从原始 prt 另存。


【单位如果要改】
打开 import_xt_to_prt.py，把开头的 UNITS = 1 改成 2 就是英寸。
（1 = 毫米，2 = 英寸）


【故障排查】
- bat 报 "not found"：没自动找到 NX 安装路径 → 改用 NX 菜单执行，效果一样。
- 还报编码错误：把整个文件夹挪到纯英文路径下再跑，例如
  C:\nxpkg\ → x_t 在 C:\nxpkg\xt\，输出落在 C:\nxpkg\x_t转prt\
  （输出目录的父路径也必须纯英文）。
- 导入数不对：对照上面的实体数表逐个查，[FAIL] 行会写明是哪个文件。
