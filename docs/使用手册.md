# NX 分层拉伸自动化 —— 使用手册（v1.40）

> 本手册写给**使用者**。目录里的 `AGENTS.md` 是给 AI/开发者看的接手文档，
> 日常使用不需要读它。
>
> 最后更新：2026-09-02

---

## 一、这套工具是干什么的

读取 AutoCAD 导出的 2D 图纸（DXF），在 NX 里自动完成：

1. 按图层把 2D 轮廓拉伸成 3D 实体（分流板/假体/各孔层/出线槽）；
2. 把 `stdparts\` 文件夹里的标准件 .prt 自动摆到图纸对应位置（可按需在板上切出型腔）；
3. 直建 JRT 加热条（含倒圆/圆顶/出线端删面/异形自动降 R 重试）；
4. 全部完成后**移除参数**——特征树清空只留实体。

## 二、文件说明（各文件是干什么的）

| 文件/目录 | 作用 | 谁维护 |
|---|---|---|
| `nx_extrude_runner.py` | 主脚本：全部自动化逻辑。**只播放它，不要编辑** | 开发者 |
| `nx_std_config.py` | **参数配置文件**：标准件默认参数（参考点 ref 已全部归零）、Z基准模式、联动偏移、加热条参数、NX 图层分配等。**你要调参数就改这个文件** | **你** |
| `tools\nx_zero_ref.py` | **归零工具（v1.36 新增，v1.37 起位于 tools\）**：日记播放后逐件点选定位点，自动把标准件平移到"定位点=零件原点"并输出归零副本。新增标准件时用它归零一次 | 你+工具 |
| `nx_extrude_params.json` | 运行记忆：你在对话框里勾选/修改过的值。脚本自动读写（损坏时自动改名 `.bad-*` 隔离留证，不会覆盖丢失现场） | 不要手编 |
| `logs\` | 运行生成物：dlx 对话框文件 / 运行报告 / 调试脚印。每次运行自动生成，**整包可删**（下次运行重建） | 自动 |
| `stdparts\` | 标准件 .prt 库，必须与脚本同目录 | 你放零件 |
| `journals\` | 手工操作录制的期刊（历史依据，留档） | 留档 |
| `tools\` | 工具脚本：归零工具、兼容探针、api 探针/提取、dlx 语法参考、archive 迁移留档 | 开发者 |
| `tools\NX向下兼容工具\` | **旧版 NX（8/10/12…）下放工具**：export_xt.py 把 stdparts 母版导出 x_t（放包内 `xt\`），整个文件夹拷到低版本机器双击 `一键导入.bat` 还原 prt（产出在包内 `x_t转prt\`，prt 版本=执行导入的本机 NX 版本），还原的 prt 直接放回 `stdparts\` 覆盖同名即可。详见包内 `使用说明.txt` | 开发者+你 |
| `test\` | 回归测试套件（test01x / test123 / test_ref / test_batch111 + fixtures 测试图纸） | 开发者 |

## 三、整个文件夹可随意移动

`NX\` 文件夹是**自包含**的：脚本按自身所在位置查找配置、标准件库、
记忆和生成物，没有任何写死的路径。把它整体移动/拷贝到其它目录、
其它盘符、甚至其它装了 NX 的电脑，都能直接正常工作。
自 v1.40 起脚本**向下兼容 NX 10 / 12**（建模主链、圆角、删面、装配、对话框均实测通过）；
唯一注意：标准件 `.prt` 只向下不向上兼容，交付旧版时须用 `tools\NX向下兼容工具\`
把母版还原成目标机版本的 `.prt` 再放回 `stdparts\`（详见工具包内使用说明）。

`__pycache__` 文件夹（如出现）是 Python 字节码缓存——无害、可删、
会自动重建；当前版本已在脚本内禁用其生成，正常使用不会再出现。
`logs\` 里的报告/调试脚印同理，整包可删。

## 四、快速上手（每次运行的流程）

前提：NX 2312 已启动，`stdparts\` 里有你要用的标准件（v1.36 起参考点已全部归零，**不需要**再填任何坐标）。

1. **工具 → 日记 → 播放** → 选 `nx_extrude_runner.py`；
2. **窗口① 标准件选择**：勾选本次要加载的件（勾选自动记忆，新件默认不勾）；
3. **窗口② 分层拉伸**：确认 DXF 路径（文件不存在会被弹窗拦下）；改 FLB 起始/结束时，LS/RZ/DK/DP/JT/CX/JRT 按联动偏移自动跟随（JT 有普通/针阀两种模式，见 5.5；CX 起始恒=JT 起始；也可单独再改）；
4. **窗口③ 标准件参数**：每件一组（定位图层/Z基准/偏移/布尔/方向），有"恢复默认"按钮；
5. **确定**执行。日志在下方信息窗；完成后特征树只剩实体。

**重跑**：直接再播放一遍即可，上一轮产物会被自动清理重建（两遍结果一致）。

## 五、图层约定（2D 图纸要按这个准备）

| 图层 | 内容 | 拉伸行为 |
|---|---|---|
| FLB | 分流板轮廓 | 基准体（其它层从它上面减） |
| JT / CX | 假体 / 出线槽 | 普通拉伸（CX 与 CXK 曲线合并闭环） |
| LS / RZ / DK / DP | 螺丝孔 / 热咀孔 / 点孔 / 垫片 | 拉伸后从 FLB 减去 |
| CXK | 接线盒定位线（一条线） | **只定位不建模**（曲线并入 CX 闭环） |
| JRT | 加热条轮廓 | 由脚本直建（含两端倒圆等工序） |

某层"起始=结束"则跳过该层。每个 DXF 图层会导入到 NX 的 11~70 图层区（每轮重建，**别把自己的图形放在 11~70 层**，会被当产物清掉；自用图形放 1~10 层或 70 层以上）。

## 六、配置文件 nx_std_config.py 怎么配

配置文件内部有逐项详细注释，这里讲清楚最常用的三件事。**改完保存、重开对话框即生效**；但注意：对话框里改过的值存在 json 里、优先级更高——想让 config 生效就点该件"恢复默认"，或删 json 重来。

> **v1.35 提示**：配置版本号已升至 4，首次运行会自动丢弃旧记忆——各层拉伸距离回默认、标准件参数回 config 出厂值（你实测填写的参考点 ref 将生效）。属预期行为，把各层拉伸距离重填一次即可；改错 config（非法值/语法错）现在会**弹窗提示具体原因**，不再静默回默认。

### 5.1 新增一种标准件（三步）

0. **若 prt 原点不在插入位置**：先跑归零工具 `nx_zero_ref.py`（日记播放，逐件点定位点，自动输出归零副本）；
1. 归零后的 `xxx.prt` 放进 `stdparts\`；
2. 在 config 的 `STD_PART_DEFAULTS` 表加一行：
   ```python
   ("定位块-10.prt", {"layer": "DK", "r_min": 0.0, "r_max": 3.0,
                      "z_mode": "FLB_BOTTOM", "bool_mode": "PLACE",
                      "ref": [0.0, 0.0, 0.0]}),
   ```
3. 重开对话框，窗口①勾选它。

### 5.2 参考点 `ref`（v1.36 起已全部归零，**无需维护**）

`ref` = **零件坐标系里、零件上"对准图纸定位点"的那个点**（mm），装配时该点与图纸定位点重合。

- **现状**：v1.36 用归零工具把 14 个标准件全部归零——定位特征已平移到零件原点，config/json 里所有 `ref` 恒为 `[0.0, 0.0, 0.0]`，**再也不用测量和填坐标**；
- **新增标准件**（两条路任选）：①设计 prt 时把原点建在插入位置（ref 写 `[0,0,0]`）；②用归零工具处理（日记播放 `nx_zero_ref.py`，逐件点定位点，自动输出归零副本到 `stdparts_归零\`）；
- **两级匹配**仍有效：先查**精确文件名行**，再落**关键词行**（`"大水口"`，该族默认行为）。⚠ 复合名（如"主进胶与中心定位垫片-30"）必须有自己的精确行，否则会被"垫片"关键词错误命中；
- **同名注意**：归零件与原件文件名相同，NX 不允许同名部件并存——打开归零件验证前先关闭会话里的原件（归零工具写回后会自动关，手工验证时留意）。

### 5.3 Z 基准（z_mode）与新增基准

- Z 高度 = **基准面 + Z偏移**。默认三种基准：`FLB_TOP`（FLB 顶面）/ `FLB_BOTTOM`（底面）/ `CX_TOP`（CX 顶值）；
- **想加新基准**（如"JT 顶面"）：在 config 的 `ZMODE_DEFS` 表加一行 `("JT_TOP", "JT顶面", "JT", "TOP")` → 规则行即可写 `"z_mode": "JT_TOP"`，下拉框自动多一项。

### 5.4 其它可配的全局参数（都在 config 里，含注释）
### 5.5 JT/CX 联动（普通/针阀，v1.37/v1.38）

JT 起止随 FLB 实时联动，窗口②"普通拉伸图层"组顶部的 **JT 联动模式** 下拉切换：

| 模式 | FLB -40/-85 时 | 偏移默认值 |
|---|---|---|
| 普通模式 | JT -30/-100 | 起点 +10、终点 -15 |
| 针阀模式 | JT -25/-100 | 起点 +15、终点 -15 |

- 联动后 JT 仍可单独改；再动 FLB（或切换模式）会按当前模式重推；
- 偏移默认值在 config 的 `JT_LINK_MODES` 表可改，默认模式 `JT_LINK_DEFAULT`；模式选择记忆到 json；
- **CX 出线槽同步联动（v1.38 起，v1.40 修正）**：CX 起始恒=JT 起始，**CX 结束 = CX 起始 − 35**（槽深固定；config `CX_LINK_END_OFFSET` 可改，默认 35，起始 -30 → 结束 -65）。改 JT 起始或 FLB 会带动 CX；改 JT 结束不影响 CX（结束只看自身起始，不再跟 JT 结束）。
- 配合归零件（v1.36 起）使用，JT 与标准件孔位一次对齐。

| 配置项 | 含义 |
|---|---|
| `LINK_OFFSETS` | 第二页改 FLB 时其它层的联动偏移（RZ 突出 13 / DK 缩入 3 / DP 台阶 6.7023，可按定位件实测改） |
| `JRT_INTRUSION_DEFAULT` | 加热条入侵深度默认 7.5 |
| `JRT_OFFSET / JRT_DRAFT` | 加热条壁偏置 5.0 / 拔模角 2.0° |
| `JRT_COLOR_STRIP / JRT_COLOR_MODEL / JRT_TRANSLUCENCY` | 加热条/模型颜色与透明度 |
| `NX_LAYER_START / NX_LAYER_JRT / NX_LAYER_DYNAMIC_START / NX_LAYER_MAX` | NX 图层号分配（默认 11 起 / 18 / 19 / 70） |
| `LAYER_START_DEFAULTS` | 各图层"全新记忆时"的初始拉伸距离 |
| `STD_MAX_ANCHORS` | 单件最大放置数护栏（默认 200） |
| `JRT_BLEND_R / R_STEP / R_MIN_DEFAULT` | 加热条倒圆 R / 降级步长 / 下限（3.9/0.1/3.7，**永不进记忆**，每次打开恒为此值） |

## 七、加热条说明

- 轮廓画在 JRT 图层（**必须闭合**；断口 ≤1mm 的缝会自动桥接，大缺口会跳过并在日志报断口坐标——回 2D 补线）；
- 两端工艺自动完成：嵌入端倒圆 → 出线端删面 → 切槽 → 圆顶倒圆。圆顶从 R3.9 起试，出现异形自动撤销降 R 重试到下限（实物判据：倒圆后体内残留样条拔模面=异形）；
- 底侧条自动镜像生成。

## 八、注意事项（常见坑）

1. **改了 config 没反应** → json 里的旧值优先。点"恢复默认"，或删 `nx_extrude_params.json`；
2. **重启 NX 再测新脚本版本**——NX 会缓存旧代码，改完立即跑可能跑的是旧版；
3. **11~70 层是脚本管理区**，自有图形放 1~10 层或 70 层以上；
4. DXF 用 AutoCAD 另存导出；图中不要有重复线/碎线（开链会被报断口坐标）；
5. **同一 DWG 只对应一套参数记忆**——换图纸后各层的拉伸距离记得核对；
6. 标准件没出现 → 看弹窗/日志：勾了没？图层/半径筛得到锚点吗？（v1.36 起 ref 已全部归零，不再有"缺 ref"问题）
7. `logs\` 里的 dlx/报告/脚印都是自动生成的临时文件，整包随手删没关系；
8. 升级/更换脚本版本前**手动备份一份**（本项目约定：不做自动备份）；
9. **轮廓别用多段线（LWPOLYLINE）画**——本工具只认直线/圆弧，运行时会弹窗+日志警告并跳过这些轮廓；回 AutoCAD 用 `EXPLODE` 炸开成直线/圆弧再跑；
10. **窗口②先点"应用"再点"取消"= 中止整个流程**（v1.35 起 Cancel 会清掉之前暂存的参数，不会再"取消了还继续执行"）。

## 九、开发与测试（给需要改脚本的人）

改动直接针对主脚本/config（改前请手动备份一份）→ `python nx_extrude_runner.py --selftest`（断言总数随 config 标准件条目数浮动）→ `run_journal` 跑 `test\test_batch111.py`（3Dtest 全家族两遍回归）与 `test\test01x.py`（加热条）→ 用户实测。回归套件在 `test\`（含自带测试图纸 `fixtures\`），运行生成物在 `logs\`。
