> **支持环境**：Siemens NX 10 / NX 12 / NX 2312 及以上版本（兼容 Python 3.3 ~ 3.12+）。  
> **最后更新**：2026-09-19（随 v3.4：移面选择范围改为**[底+40, 顶+40]**——咀尖底部 40mm 固定、范围内一切面都移、所有被选实体的面合成一份一起移；移完**定位点点对点回位**，治 Z 轴偏移；随 v3.3/v3.2：先摆正再移面、探步校准方向、锚点记录顺序修复；随 v2.13：RZ/DK 默认 0/0 不做、热咀布尔默认"放置+减去"、替换两页去记忆）

## 一、系统概述与核心能力

本套工具通过 Siemens NX Journal（日记播放）运行，读取 AutoCAD 导出的 2D DXF 图纸，自动完成从 2D 线框到高精度 3D 实体的全流程建模：

1. **分层拉伸与布尔切割**：
   - 自动识别分流板（FLB）基准体轮廓；
   - 自动拉伸假体（JT）、出线槽（CX）等普通实体；
   - 自动拉伸螺丝孔（LS）、热咀孔（RZ）、点孔（DK）、垫片（DP）并从分流板上精准布尔减去（支持多通道板自动命中所属实体）。
   - **v2.13 变更**：`RZ` 与 `DK` 的窗口②默认值改为 `0/0`（= 这两层不做）并**解除与 FLB 的联动**——热咀的让位孔改由热咀标准件按"放置+减去"布尔自己挖；需要旧行为时自行把数值改回非 0。
2. **标准件自动装配与特征切割**：
   - 扫描 `stdparts\` 库中的标准件 `.prt` 文件；
   - 根据图纸圆心锚点自动计算三维空间位移与插入姿态（+Z 插入 / -Z 翻转）；
   - 通过组件装配（AddComponent）导入，利用实体提升（Promotion）和布尔运算在分流板上直接切槽或合体；
   - **v2.13 变更**：热咀族（大水口 / 点胶口 / 热咀 / nozzle，关键词可配）的布尔方式默认改为**放置+减去**。
3. **JRT 加热条闭环建模**：
   - 自动解析加热条轮廓（支持 ≤1mm 细小断口自适应桥接；导轨线顺原方向画过头、压在长线上的重复短描线自动剔除，不再把闭链拆散导致整根条漏做）；
   - 自动完成两端工艺：嵌入端倒圆 → 出线口删除面愈合 → 实体切槽 → 圆顶倒圆（内置异形检测、体积异常与"空转"判定——圆角被 NX 裁成缝、体积几乎没变也按失败降 R 重试）；齐平端起试 R 按条高收小（条高一半再留 0.05 余量、不低于最小 R），避免与嵌入端圆角碰头；删除面位置（出线口）优先按 `JRTFBX` 标记图层定位（沿封口线描短线取中点，或横跨槽口画长线取两端点，两种画法兼容；与 JRT 线重合的标记不重复拼接，只当定位用；离条超限或与轮廓算出的出线口差太远的标记自动忽略），图纸上没有标记时按条自身封闭轮廓自动辨认出线口，两端口全开的条两端都删；嵌入端倒圆或删面没做成时，齐平端就不倒圆、该端留直角；
   - 上下表面自动镜像生成双侧加热条，并设置独立着色与透明度。
4. **无参数化归整（去参）**：
   - 建模全流程完成后自动**移除参数**（Remove Parameters），清空特征树历史依赖，仅保留纯净几何哑实体（避免装配循环依赖与超大文件负担）。
5. **增量清理与无损重跑**：
   - 每次重新播放时，自动识别并清理上一轮生成的特征、体、组件与曲线，不影响用户在工作部件中自绘的非脚本图形。

|---|---|---|

## 三、快速上手（标准运行流程）

### 1. 运行前准备
- 启动 Siemens NX（NX10 / NX12 / NX2312 均可）；
- 新建一个毫米（mm）建模部件，或打开已有的工作部件；
- 准备好待加工的 AutoCAD 2D 图纸（**v2.2 起直接支持 `.dwg` 图纸**，亦兼容 2000/2004/2007 格式的 `.dxf` 文件）。

### 2. 标准三段式交互流程

1. **启动脚本**：
   - 菜单栏点击：**【工具】(Tools) → 【日记】(Journal) → 【播放】(Play)**；
   - 在文件选择框中选中项目根目录的 **`nx_extrude_runner.py`**，点击运行。

2. **窗口①：标准件选择对话框**（有已配置标准件时弹出）：
   - 列表列出 `stdparts\` 中扫描到的所有标准件；
   - 勾选本次图纸需要装配的标准件（脚本自动记忆上次勾选；新添加的零件默认不勾选）；
   - 点击【确定】进入下一步；点击【取消】立即中止本次流程。

3. **窗口②：主参数与分层拉伸窗口**：
   - **图纸文件 (DWG / DXF)**：在顶部浏览并选择待处理的 `.dwg` 或 `.dxf` 文件；
     > 若选取的是 `.dwg`，系统将在后台自动静默转换为标准 DXF 并在建模结束后 100% 自动安全销毁清理，无需人工预先另存；
   - **JT 联动模式**：选择“普通模式”或“针阀模式”；
   - **分流板与各图层距离**：
     - 输入 `FLB` 的起始距离与结束距离（支持负坐标，如 `-40.0` 到 `-85.0`）；
     - 修改 `FLB` 数值时，联动层（`LS`、`DP`）以及假体（`JT`）、出线槽（`CX`）、加热条（`JRT`）会按工程预设联动偏移**自动推导跟随**；
     - **`RZ` 与 `DK` 已解除联动（v2.13）**：默认 `0/0` = 这两层不做（拉伸时整层跳过），改 `FLB` 也不会带动它们；需要做这两层时自行填入非 0 数值；
     - 某层若“起始 == 结束”，该层自动跳过；
   - **【镜像】按钮**（`FLB` 组内，v2.5 新增）：
     - 一键把 `FLB` 起止距离翻到另一侧（数值翻符号、先后次序不变，如 `-40/-85` → `40/85`），联动层（`JT`/`CX`/`LS`/`DP`）与加热条随即按**常规联动公式整体重推**——与您手动输入翻转后 `FLB` 的联动结果完全一致；
     - `RZ`/`DK` 不联动（v2.13），镜像不改动它们的数值；
     - 镜像会覆盖联动层的手工微调（恢复为联动值），有特殊工艺时镜像后再单独修改即可。
   - 点击【确定】完成参数暂存。

4. **窗口③：标准件参数微调窗口**（每件对应一个可收起组）：
   - 针对窗口①勾选的标准件，核对定位图层（如 `RZ`、`LS`）、Z 基准（如 `FLB_BOTTOM`、`FLB_TOP`）、偏移量（X/Y/Z）以及布尔模式；
   - 热咀族（大水口/点胶口/热咀/nozzle）的布尔方式默认**放置+减去**（v2.13）：件放着的同时直接把让位孔挖进 FLB；
   - 支持单件点击【恢复默认】按钮还原为出厂设置；
   - 点击【确定】（或【应用】）开始全自动建模！

5. **执行与输出**：
   - NX 信息窗口（ListingWindow）将逐行打印当前建模步骤与统计；
   - 运行完毕后，图形区自动重绘并呈现 3D 实体，特征树被清空（仅留去参哑实体），完成交付。

## 四、AutoCAD 图纸规范与图层约定

为确保自动化脚本能够精确提取轮廓和装配特征，AutoCAD 图纸请遵循以下图层命名与图元标准：

| 图层名称 | 典型图元 | 自动化建模行为 | 说明与工艺约束 |
|---|---|---|---|
| **`FLB`** | 封闭多段直线/圆弧 | **基准体拉伸** | 分流板主轮廓。必须封闭，支持双通道等多实体布局。其余减层将自动减入该实体。 |
| **`JT`** | 封闭多段直线/圆弧 | **普通拉伸** | 假体轮廓。拉伸为独立实体，不与 FLB 布尔。起止尺寸随 FLB 联动。 |
| **`CX`** | 封闭槽线轮廓 | **出线槽拉伸** | 普通独立实体。自动与 `CXK` 接线盒曲线并入闭环。 |
| **`CXK`** | 直线段（短线） | **仅定位参考，不拉伸** | 接线盒定位线。线段中点作为接线盒标准件的放置锚点，曲线参与 `CX` 闭环。 |
| **`LS`** | 圆（CIRCLE） | **布尔减去** | 螺丝孔。圆心作为 LS 标准件插入点，同时从 FLB 实体中减去贯穿穿孔。 |
| **`RZ`** | 圆（CIRCLE） | **布尔减去（v2.13 默认 0/0 不做）** | 热咀孔。圆心作为大水口/点胶口等标准件插入点。v2.13 起该层默认不拉伸挖孔，让位孔由热咀标准件按"放置+减去"自己挖；需要单独挖孔时在窗口②填入非 0 起止值。 |
| **`DK`** | 圆（CIRCLE） | **布尔减去（v2.13 默认 0/0 不做）** | 点孔/销孔。v2.13 起默认不做、不随 FLB 联动；需要时在窗口②填入非 0 起止值。 |
| **`DP`** | 圆或矩形环 | **布尔减去** | 垫片槽。支持内外同心嵌套环（外环为体，内环自动挖孔），并从 FLB 减去。 |
| **`JRT`** | 连续直线/圆弧链 | **加热条直建** | 加热条轮廓。一根条要画**两圈线**：**最内侧和最外侧那条**（首尾相接成闭合轮廓，含 2 条 8mm 封口线）才是建模用的；中间那条（可能多条）是量加热条长度用的中心线，**不参与建模**（它两头不相接，日志会提示"跳过不建模"，属正常）。两端自动倒圆并愈合删除面。 |
| **`JRTFBX`** | 直线段（短线或横跨长线） | **仅定位参考，不拉伸** | 加热条封闭线标记。定删面位置（出线口）用：沿封口线描的短线取中点、横跨槽口画的长线取两端点，两种画法都认。与 `JRT` 线完全重合的标记不会重复拼接（只当定位用，日志会说明）；离条超过 10mm 或与轮廓算出的出线口差太远的标记自动忽略。 |

> [!CAUTION]
> **严禁在建模图层使用多段线（`LWPOLYLINE`）**：  
> 本工具底层只解析标准的 `LINE`（直线）、`ARC`（圆弧）和 `CIRCLE`（整圆）。若图纸中存在未炸开的多段线，脚本会跳过该实体并在日志弹出警告。**请在 AutoCAD 中全选图形并执行 `EXPLODE`（炸开）命令后再另存 DXF。**

> [!NOTE]
> **图层安全保护区**：  
> 脚本将导入的 DXF 曲线统一放入 NX 图层 **101 ~ 170** 区间，并在每次运行前只清理自己生成的那部分（带 CAD3D 标记的特征/实体/曲线）。**用户自行绘制的参考线、毛坯模型请放在图层 1 ~ 100 或 170 以后**，以免被误当历史生成物清除。

## 五、参数配置指南（nx_std_config.py）

当工程标准、材料厚度或零件型号变更时，直接修改根目录的 `nx_std_config.py`，无需改动任何代码。

### 1. 核心联动参数表（`LINK_OFFSETS`）
控制窗口②中修改 `FLB` 厚度时，其它各层距离的自动推导量：
```python
# 基准: FLB 顶面为 top, 底面为 bottom
# LS 恒与 FLB 同高(无偏移); DP 台阶厚度 = bottom + 此值
# v2.13: RZ(热咀孔)/DK(点孔) 已解除联动(默认 0/0 不做), 旧偏移量作废删除
LINK_OFFSETS = {
    "DP": 6.7023,
}
```

### 1b. 热咀替换长度对齐（v3.4 = 完全照手动的做法）
配合 `nx_std_replace_runner.py`：换热咀时按你录制的日记口径自动对齐——**先摆正位置，再调长度，最后把定位点搬回，三步分开**：
```python
NOZZLE_FAMILIES = ["热咀", "大水口", "点胶口", "nozzle"]  # 文件名含任一关键词才算热咀
NOZZLE_BAND_UP = 40.0      # 移面选择范围整体上移量 (mm): 咀跨 z [0,100] → 选 [40,140]
```
- **① 先原位摆正**：新件按旧件锚点直接放置（定位点 = 锚点），**位置从放置那一刻就正确**；
- **② 移面选择范围 = 底面到顶面再整体上移 40mm**（2026-09-19 定案）：咀跨 z [0,100] 就选 [40,140]——咀尖底部 40mm 固定不动（不在范围内），**范围内被选中的一切面都要移动**（不分平面/侧面）；**所有被选中实体的面合成一份、一次「移动面」一起移**（有多少实体被选中，就移多少实体中被选中的面，不能只移一个实体的），单步 ≤10mm（大了相邻几何会被扯脱）；
- **③ 方向现场校准，不猜符号**：先移一小步（2mm）复测，量出"每移 1mm 总长变多少"（符号各件不同），再按斜率补齐，移完复测、不齐再补；
- **④ 定位点回位**：定位点落在范围内时会被移面带走——移完把**整个新件**用「移动对象-点对点」平移回去（先去参，提升体是链接体不许整体移动），让定位点与放置点重新重合；定位点在咀尖底部 40mm 固定段内时不会被带走，无需回位；
- 旧件长度 = 按实例各算各的"主平面口径"顶减底（见下文 Q7）；新旧等长免调；
- 想关掉整项功能：把 `NOZZLE_FAMILIES` 改成 `[]`。

### 2. JT / CX 联动模式切换（`JT_LINK_MODES`）
定义窗口②顶部下拉框可选的假体联动比例：
```python
JT_LINK_MODES = {
    "普通模式": (10.0, -15.0),          # JT起点 = FLB_top + 10; JT终点 = FLB_bottom - 15
    "针阀模式": (15.0, -15.0),          # JT起点 = FLB_top + 15; JT终点 = FLB_bottom - 15
}
JT_LINK_DEFAULT = "普通模式"
CX_LINK_END_OFFSET = 35.0               # CX 槽深固定 35mm (CX 终点 = CX 起始 - 35)
```

### 4. NX 高位图层分配与冲突智能避让（v2.1 新增）
系统默认将所有自动化生成的曲线放入 **101 ~ 170 高位图层**，把低位常用的 1 ~ 100 图层 100% 完整留给用户的日常自绘图形：

- `NX_LAYER_JRT = 118`：JRT 加热条轮廓（参考线，不建模）
- `NX_LAYER_JRTFBX = 119`：JRTFBX 加热条封闭线标记（只用来定删面位置）
- `NX_LAYER_DYNAMIC_START = 120`：其余 DXF 图层（0、LD、YXB、CXK 等）从 120 起动态排布
- **智能避让机制**：若当前模型在 101~107 中已存在用户自绘图形，系统在建模前会自动探测，并智能滑动平移到一段连续干净的空闲图层（如 131~137），实现 100% 物理级零混层保护！

| 开关 | 默认 | 作用 |
|---|---|---|
| `DWG_CACHE_ENABLE` | `True` | 同一张 DWG 图纸未改动（路径/大小/修改时间均未变）时，第二次起直接复用 `logs\` 下的转换结果，**完全跳过起 AutoCAD 转换这一步**；图纸改存后自动失效重转。缓存默认保留 7 天（`DWG_CACHE_MAX_AGE`，秒）自动清理。 |

## 六、标准件归零与添加新零件

为彻底解决标准件在不同坐标系下插入位置偏移、每换一个零件就要手工测量坐标的繁琐问题，系统采用了**标准件原点归零机制**（自 v1.36 起）。

### 什么是归零？
标准件 `.prt` 建模时的原点（0, 0, 0）直接平移对准其理论插入定位点。归零后，在配置表里该零件的 `ref` 坐标恒为 `[0.0, 0.0, 0.0]`，再也无需人工维护三维坐标！

### 新增标准件三步法：

1. **平移归零**：
   - 若您新设计或导入的 `xxx.prt` 原点不在插入基准处，在 NX 中运行日记：选择 `tools\nx_zero_ref.py`；
   - 依序弹出点选窗口，在屏幕上捕捉拾取该零件的定位点，工具自动将几何整体平移并另存归零后的 `.prt`；
   - 将归零后的 `.prt` 放入根目录的 `stdparts\` 文件夹。

2. **配置默认规则**：
   - 打开 `nx_std_config.py`，在 `STD_PART_DEFAULTS` 表中追加一行精确文件名规则：
   ```python
   ("大水口-45.prt", {
       "layer": "RZ",                  # 依据 DXF 的 RZ 图层圆心定位
       "r_min": 0.0, "r_max": 20.0,    # 捕获图层圆的半径范围 (mm)
       "z_mode": "FLB_BOTTOM",         # 贴齐 FLB 底面
       "bool_mode": "PLACE_SUBTRACT",  # 放置并减去型腔
       "dir": "+Z",                    # 插入朝向
       "off_x": 0.0, "off_y": 0.0, "off_z": 0.0,
       "ref": [0.0, 0.0, 0.0],         # 已归零，恒写全 0
   }),
   ```

3. **运行验证**：
   - 播放 `nx_extrude_runner.py`，在窗口①中勾选新增的零件，在窗口③中确认其基准面与布尔模式后点击执行。

## 七、JT / CX / 加热条联动机制

```mermaid
graph TD
    FLB[“分流板参数 (FLB Start / End)”] -->|”JT 联动偏移 (+10/-15 或 +15/-15)”| JT[“假体 (JT)”]
    FLB -->|”LINK_OFFSETS”| Holes[“联动孔系 (LS / DP)”]
    RZDK[“RZ / DK (v2.13 起独立, 默认 0/0 不做)”] -.->|”不联动”| FLB
    FLB -->|”顶部深度 -7.5”| JRT[“加热条区间 (JRT)”]
    JT -->|”起始点恒等”| CX_Start[“出线槽起始 (CX Start = JT Start)”]
    CX_Start -->|”- 35mm 固定深度”| CX_End[“出线槽结束 (CX End = CX Start - 35)”]
```

- **全自动联动响应**：在窗口②中无论您调整 `FLB` 厚度还是切换“普通模式 / 针阀模式”，联动层（JT / CX / LS / DP / JRT）的起止距离均在毫秒级内自动按工程几何规范换算更新。
- **RZ / DK 独立（v2.13）**：热咀孔与点孔不再随 FLB 联动，默认 0/0 = 不做（热咀让位孔由热咀标准件自己挖），需要时手动填数。
- **解耦保护**：出线槽 `CX` 的槽底深度独立锁定为 35mm，不会因假体 `JT` 终点的变动而发生槽底击穿板底的严重失误。

## 八、低版本 NX（10/12）向下兼容操作

NX 的 `.prt` 模型格式具有“**向下兼容，不向上兼容**”的特性（高版本 NX 保存的 `.prt` 无法在低版本 NX 中直接打开）。

如果您需要将本套工具部署至工厂的 **NX 10** 或 **NX 12** 电脑上：

1. **Python 脚本层面**：
   - 本套系统代码已通过全量 AST 兼容性审计，无任何 Python 3.6+ 高版本语法（严禁使用 f-string、类型注解、async 语法等）；
   - 在 NX 10（Python 3.3.2）与 NX 12（Python 3.6.1）上**核心建模主链无需修改任何代码**，可直接运行。以下两项边缘能力在 NX 10 上不可用，**不影响建模**：
     - **直接选 `.dwg` 自动转 DXF 不可用**：该路径依赖 Python 3.5+ 的 `subprocess.run`，NX 10 的解释器是 3.3.2。规避办法：图纸先另存为 2004 格式 `.dxf` 再用（NX 12 无此限制，可直接选 `.dwg`）。
     - **`--selftest` 离线自检不可用**：自测套件用到 Python 3.5+ 的 `ast.AsyncFunctionDef`。规避办法：装一个 Python 3.6+ 跑自测，或改用 NX 内的 `batch_smoke.py` 验收。
   - 完整移植清单与逐步骤操作见本地《移植手册》（`docs\移植手册.md`，**不入版本库**，随交付包单独提供）。

2. **标准件模型还原操作**：
   - 进入目录：`tools\NX向下兼容工具\`；
   - 将该目录整体拷贝至目标低版本 NX 机器；
   - 双击执行目录内的 **`一键导入.bat`**；
   - 工具会自动调用本机低版本 NX 的后台程序，将通用的 Parasolid 格式（`xt\` 目录下）还原转换为当前机器版本的 `.prt` 文件（输出于 `x_t转prt\` 目录）；
   - 将生成的低版本 `.prt` 文件拷贝覆盖回根目录的 `stdparts\` 文件夹即可。

## 十、常见问题排查与避坑指南

### Q1：修改了 `nx_std_config.py`，但在对话框里没有生效？
- **原因**：NX 对话框优先读取上次保存在 `nx_extrude_params.json` 中的交互记忆。
- **解决方法**：在窗口③中点击该标准件的【恢复默认】按钮；或直接删除根目录下的 `nx_extrude_params.json`，重开对话框即可恢复全套出厂配置。

### Q2：修改了代码后在 NX 播放日记，行为似乎没有改变？
- **原因**：NX 图形会话驻留内存，Python 的 `sys.modules` 会缓存旧模块。
- **解决方法**：v2.0 门面已内置模块驱逐重载机制，保存文件后**直接重新播放**即可生效；若遇到深层 C++ 扩展残留，可重启一次 NX 会话。

### Q3：DXF 导入后部分图层轮廓没有生成 3D 实体？
- **排查步骤**：
  1. 查看 NX 信息窗口日志中的【解析】行；
  2. 若日志提示 `有脚本不认识的图形`（多为 `LWPOLYLINE` 多段线），说明图纸中使用了多段线，请在 AutoCAD 中使用 `EXPLODE` 炸开后重新保存；
  3. 若日志提示 `有 N 条线两头没接上`（中间那条量长度的中心线属正常），按日志给出的断口坐标，在 CAD 对应位置补齐缺口。

### Q4：标准件没有被自动放置到分流板上？
- **排查步骤**：
  1. 检查窗口①中该标准件是否被勾选；
  2. 检查该标准件在配置表里的 `layer`（图层）和 `r_min ~ r_max`（半径区间）是否覆盖了图纸中的圆；
  3. 确认 `stdparts\` 文件夹下是否存在对应文件名的 `.prt`。

### Q5：如何完全清空历史运行缓存？
- 直接删除根目录下的 **`logs\`** 文件夹与 **`nx_extrude_params.json`** 文件即可（`logs\` 内含 v2.4 的 DWG 转换缓存 `_dwg_cache_*.dxf`，删除后下次运行自动重转）。下次运行脚本会自动以初始状态重新生成。

### Q6：替换标准件的窗口为什么不记得上次选的？（v3.1）
- **这是设计如此（v3.1 定案）**：替换向导的两页（替换关系页 + 参数微调页）**都不读、不写任何记忆**——替换关系每次从"不替换"现选，参数每次从 `nx_std_config.py` 出厂默认开始，避免上次换件的映射/参数悄悄影响这一次。主脚本（建模）的记忆机制不受影响。

### Q7：换热咀后长度不对/没对齐怎么办？位置偏了怎么办？
- **选面范围（2026-09-19 定案）**：= 热咀底面到顶面再整体上移 40mm（咀跨 [0,100] → 选 [40,140]）。咀尖底部 40mm 是固定端不动；**范围内一切被选中的面都要移**（不分水平/侧面），所有被选实体的面合成一份、一次「移动面」一起移，单步 ≤10mm；
- **先探一小步再补齐**：脚本先移 2mm 复测，量出这根件"移 1mm 总长变多少"（斜率），再按斜率一步补齐、复测，不齐再补（有轮数上限）。日志每处打 `【长度对齐】… 新件 N 个体, 按主体平面量 Z … → 长 … (旧件 …)` 与对齐结果行（含带内共移多少毫米、方向斜率），拿数字就能核对；
- **长度是怎么量的（主平面口径，2026-09-18 定案）**：**顶 = 朝上（法向 +Z）的平面里 z 最高的那个，底 = 朝下（法向 −Z）的平面里 z 最低的那个**，两者之差就是长度。**顶上的小凸起不参与**——点胶口-18 顶上有个 0.2043 的**曲面**台阶，用平面筛就天然排除了，量出来正是工程上的主体长度 95.9673（纯包围盒会得 96.1716）。旧件、新件**用同一口径**，否则白对齐。一侧没有平面的件（顶端是锥/球面）那一侧退回包围盒。日志会逐根打出 `【长度对齐】… 新件 2 个体, 按主体平面量 Z -111.6575~13.0000 → 长 124.6575`，旧件侧另有 `旧件实例 1: 2 个体, Z … → 长 …; 锚点 (…)` —— 拿它跟你实测的对照，对不上就是模型里有历史残留，先重跑主脚本；
- **定位点回位（2026-09-19 定案）**：定位点落在移面范围内时，移面会把它带走（件在 Z 向漂移）——脚本移完会把**整个新件点对点平移回放置点**，让定位点与放置点重新重合（与手动"移动对象-点对点"同口径）；定位点在咀尖底部 40mm 固定段内则不会被带走。回位失败时日志写明还差多少，需手动移动；
- **长度与位置都会在日志里对账**：`【长度对齐】… 移面选择范围 Z …(底+40~顶+40), 定位点(…)在范围内/是固定端` + 结果行（总长、共移多少、斜率、定位点是否已回位）；
- 族关键词（哪些零件算热咀）与范围上移量在 `nx_std_config.py` 的 `NOZZLE_FAMILIES` / `NOZZLE_BAND_UP` 配置。

### Q8：图纸没有 DK 图层时，垫片怎么处理？针阀模式下呢？
- **判据（2026-09-18 更新）**：拿垫片**自己的图层与半径**去图纸里筛一遍，**一个能放的位置都筛不出来**才算"没有 DK"。光看 DK 层存不存在不够——DK 层可能有图形，却没有一个半径落在垫片的范围里，那样垫片照样放不上；
- 命中时，主脚本在窗口③**临时**把靠 DK 定位的件（`垫片.prt`）的定位图层与半径换成**热咀**那套（层 `RZ`、半径取 `nx_std_config.py` 里"热咀"行的值），这样它也能找到位置放置；
- **Z 基准与布尔方式仍用垫片自己的设置**，只换"去哪个层找位置"；
- 这是**只影响本次**的临时改动：**不写进记忆**——换回能定位的图纸会自动变回原参数，不用手工改回来；
- 提示会写进**建模日志**（`logs/pipeline_report.txt` 开头，同时进 NX 信息窗口——复用主流水线本来就有的那个日志对象，**不会另外弹窗**）：`[CAD3D] 图纸里按 DK 定位一个位置都找不到: 垫片.prt 本次临时改用热咀的定位参数(只影响本次, 不写记忆)。`

**针阀模式不装垫片（2026-09-18 定案）**：窗口②选了**针阀模式**时，即使第一页勾了垫片，本次也**不放置**它，窗口③**不显示**它的参数——省得每次手动去取消勾选。建模日志里会写一行：`[CAD3D] 本次选的是针阀模式: 垫片.prt 不装(第三页也不显示)。`

### Q9：播放脚本后没看到中文提示？
- 脚本一启动会**弹一个小提示窗**，只说**本脚本**是干啥的（一行）；
- 控制台同时会打印三个脚本的完整清单（`run_journal.exe` 命令行跑时看得见）。NX GUI 里播日记**没有控制台**，所以以**弹窗**为准；
- （2026-09-18 定案：小窗、只说本脚本 —— 之前往信息窗口灌三行清单太啰嗦。）
