## 1. 加载契约（全部阶段的基础设施，P1 前必须定稿）

### 1.1 三条铁律

1. **子模块禁止 `import` 兄弟模块**。跨模块依赖一律由主脚本**注入为模块属性**。
2. **子模块一律扁平放在脚本同目录**，不建子包、不用相对 import。
3. **子模块缺失 = 立即弹窗并中止**，绝不静默回退（沿用 v1.35「不静默」原则）。

### 1.2 加载器（复用现成的三级梯 `_import_module_from_path`）

```python
# nx_extrude_runner.py 顶部（顺序不可调换）
import sys, os
sys.dont_write_bytecode = True          # 必须在任何子模块加载之前
sys.path.insert(0, script_dir())        # 双保险；仍以绝对路径加载为主

_MODULES = ["nx_geom", "nx_rules", "nx_dlx", "nx_selftest",
            "nx_jrt_geom", "nx_jrt", "nx_dialogs", "nx_stdparts", "nx_nxcore"]
_LOADED = {}

def _load_sub(name):
    p = os.path.join(script_dir(), name + ".py")
    mod = _import_module_from_path(name, p)      # 现成三级梯：importlib → imp → exec
    sys.modules[name] = mod                       # 让后续模块可 import（虽禁止，仍留口）
    _LOADED[name] = mod
    return mod
```

- **NX10(3.3.2)**：无 `importlib.util.spec_from_file_location` → 走 `imp.load_source`；3.12+ 移除 `imp` → 走 `exec` 兜底。三级梯已为 config 实机验证过，照搬。
- **加载失败处理**：NX 内 `NXMessageBox(Error)` 列出缺失文件清单并 `return`；`--selftest` 离线模式直接 `raise` 打印缺失清单。

### 1.3 注入契约（每个模块的 `INJECT` 清单见各阶段）

注入发生在加载后、首次调用前：

```python
def _inject(mod, **kw):
    for k, v in kw.items():
        setattr(mod, k, v)
    return mod
```

注入项分三类：

- **常量/表**：`LAYER_TABLE` `LAYER_CODES` `*_OPTS` `DIALOG_GROUPS` `JRT_FIELDS` `DEFAULT_*` `FEATURE_PREFIX`
- **共享对象**：`registry`（特征登记表）`notes()`（配置提示队列）
- **回调函数**：`extrude_curves` `_bool_feature` `_pick_target` `_mark_curve` `_fmt_num` `_sc_rule_options` `run_pipeline`
