## NX 10/12 向下兼容性评估（nx_extrude_runner v1.35）

- 产出: `docs/NX10-12兼容性评估报告.md` + `probe_nx_compat.py`（探针，自包含 ~640 行，不改现有代码）
- 关键结论:
  - NX 10 期刊 Python = 3.3.2，NX 12 = 3.6.1（python36.dll 实证），远高于传闻的 2.7 → 全文件仅 2 处真断点: importlib.util(L366/378, NX10) 与 ast.AsyncFunctionDef(仅 selftest)

  - 最大风险 = dlx/BlockStyler: 3 处硬编码 NX="2312.0.0"(L1504/1607/1673) 跨版本加载未验证；兜底 = --batch + JSON 记忆直跑
  - EdgeBlendBuilder L2894-2898 五个核心属性无守卫、L2899-2914 整块 try 需改逐属性守卫
  - 代码已有大量双签名/守卫（枚举 4 通道 L3926、DialogSizing L3972、AddComponent L2745 等）——天然多版本适配基因
- 推荐架构: 单代码库 + 能力探测（try_set/_set_if）+ 配置加载三梯 shim + dlx 版本属性参数化 + 对话框四级降级阶梯（L0 正常→L1 变体重试→L2 记忆直跑→L3 批量）
- 探针脚本: PY/VER/API/UI 四组 33 项，输出 logs/nx_compat_probe.json+csv；用户有 NX10/12 实机可闭环全部"需要验证"项
